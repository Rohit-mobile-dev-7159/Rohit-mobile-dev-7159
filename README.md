# About Me

I’m a **Data Analyst** with a technical background in **React Native, JavaScript, TypeScript and application development**.

My current focus is on **business analytics, dashboard development, data storytelling and AI-assisted analytics**.

I enjoy taking a business problem from:

```text
RAW DATA
    ↓
DATA CLEANING
    ↓
SQL / PYTHON / EXCEL
    ↓
EDA + KPI ANALYSIS
    ↓
POWER BI / DASHBOARD
    ↓
BUSINESS INSIGHTS
    ↓
DATA-DRIVEN DECISION
```

### My Analytics Focus

- Data Cleaning & Transformation
- Exploratory Data Analysis
- Advanced SQL
- KPI Development
- Excel Analytics
- Power Query
- Power BI & DAX
- Business Intelligence
- Dashboard Design
- Data Storytelling
- E-Commerce Analytics
- AI-assisted Analytics
